📊 자동 데이터 분석기

CSV나 엑셀 파일을 올리면 열을 분석하고, 요약하고, 어울리는 차트를 추천해 드려요.

1

파일 올리기

CSV(UTF-8·EUC-KR 모두 가능), XLSX 파일을 넣어 주세요. 첫 줄은 열 이름으로 읽습니다.
📂

CSV·엑셀 파일을 이곳에 끌어다 놓으세요

또는 눌러서 파일 선택 (.csv, .xlsx, .xls)

2

열 자동 분석

열마다 숫자 / 날짜 / 항목 / 텍스트를 자동으로 판별했어요.
3

자동 요약

정해진 문장 틀에 계산 결과를 채워 만든 요약입니다.

    ⚠️ 확인이 필요한 값

      4

      차트 추천

      열 종류 조합을 보고 어울리는 차트를 골랐어요. 카드를 누르면 크게 보고 축을 바꿀 수 있어요.
      5

      AI에게 물어볼 요약 복사

      원본 데이터는 빼고 열 이름·종류·통계·상위값·자동 요약만 담았어요.

      ※ 항목 열의 상위값(예: 지사 이름)은 들어갑니다. 민감한 이름이 있다면 붙여넣기 전에 직접 지워 주세요.

      입력한 내용은 이 브라우저 안에서만 처리되며 어디에도 저장·전송되지 않습니다.

      차트
